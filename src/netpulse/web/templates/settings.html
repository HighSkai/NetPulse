NAME

netpulse — a network monitor for this PC

SYNOPSIS

netpulse [--db PATH] [--port N] [--debug]

DESCRIPTION

NetPulse pings every device every {{ interval_s }} s, keeps every result in a SQLite file, and serves these pages to this PC only, on 127.0.0.1. There is no login, and nothing is sent anywhere else.
